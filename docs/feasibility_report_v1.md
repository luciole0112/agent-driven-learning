## 0. 要約（最重要点）

1. **最も重要な発見：本研究の中核アイデアと大きく重なる研究潮流が、2026年11月に急速に立ち上がっている。** MIT CSAIL の Takehi らが 2026-11-02 に "Weight-Space Programming"（WSP：LLMがニューラルネットの重みを「プログラム」として直接読み書きする。勾配は使わない）を提唱した。その後の約3週間で、CNN・ViT を LLM が道具を使って勾配なしに編集する研究（Ropinski & Kranz, arXiv:2611.26408）、LLMエージェントが反復的に重みを書いてモデルを一から構築する研究（Mehta et al., arXiv:2611.18114）、LLMが自分自身の重みを書き換えて改善する研究（Fan et al., arXiv:2611.21885）、ベンチマーク（WeightBench, arXiv:2611.18553）が相次いで出ている。
2. したがって、**「LLM Agent がネットワーク内部を観察し、誤差逆伝播を使わずに重みを直接編集する」という枠組みそのものには、もはや新規性はない**と判断する。ADLが研究として成立するためには、WSPとの差分を明確に定義し直す必要がある。
3. 一方でWSPの原典は、自らの限界として「重みの編集は、隠れていた能力の障害を取り除くことはできたが、**モデルが持っていない能力を加えることはできなかった**」と述べている（Gemma 3 270M の実験）。既存のWSP研究の大半は、**修復・除去・仕様からの書き下し**である。**データから新しい特徴を帰納的に獲得すること（＝学習）**は、まだ確立していない。ここがADLの残された中心的な問いになりうる。
4. 原理的には、勾配を使わない以上、Agentが「何をどう変えるべきか」を知る情報源は **(a) Agent自身の事前知識（意味的・視覚的知識）** と **(b) 順伝播による観察・介入から得る情報** の2つしかない。**ADLが既存の最適化手法と本質的に異なると言えるのは、(a) が探索の有効次元を桁違いに減らしていることを実験で示せた場合に限られる**、というのが本報告の中心的主張である。
5. 最小実験としては、「Agentの事前知識に名前がない人工的な局所パターン」を新しい概念として、凍結済みの小型CNNに後から獲得させる課題を提案する。意味情報を除いた条件、内部観察を除いた条件、同じ順伝播予算の進化戦略（ES）、決め打ちの規則（matched filter）を比較対象とする。

**【解釈】WSPとADLの差分（現時点）**

- WSPは主に「**仕様が言語で与えられ、Agentが答えを知っている問題**」（ゲームの規則、既知のアルゴリズム、ループ方向の除去）で成功している。ADLが目指す「**データから、Agentも知らない特徴を発見して獲得する**」ことは、ほぼ未検証である。
- WSPの原典 [1] は「持っていない能力は加えられなかった」と述べ、[3] は「新しい原理は発明しない」と述べている。これらは**ADLの中心仮説に対する直接の反証候補**であり、同時に**ADLが攻めるべき空白**でもある。
- CNNを本格的に扱っているのは [2]（と、読解のみの [7]）だけである。[2] は「LLMが編集しやすいようにCNNを逆伝播で前処理する」方向を取っており、ADLの「Agentを学習主体にする」立場とは逆向きである。
- VLMが入力画像の意味を見て、CNNの内部表現と突き合わせるという**クロスモーダルな比較**を中心に据えた研究は、今回の調査範囲では確認できなかった。ただし [2] のLLMがマルチモーダル入力を受けていたかは本文の後半を未確認のため不明である。

### 1.2 Agentによるモデル内部の観察（解釈の自動化）

- **MAIA**：Rott Shaham, Schwettmann, …, Andreas, Torralba (MIT CSAIL), "A Multimodal Automated Interpretability Agent", arXiv:2404.14394（2024, v2 2025）[9]【事実】。GPT-4V系のAgentが、入力画像の合成・編集、exemplar計算などの道具で視覚モデルのニューロンを実験的に説明する。**対象モデルの重みは編集しない**。スプリアス特徴除去の実験では、MAIAが選んだ22ニューロンの上でロジスティック回帰を学習し直している（=最終的な更新は通常の当てはめ）。さらに、均衡データを使った ℓ1 ベースライン（0.865）がMAIA（0.837）を上回っていた。
  → ADLの「観察・推論」部分の先行例。ただし「操作」は持たない。
- 【既知文献】Bills et al., "Language models can explain neurons in language models", OpenAI, 2023。Hernandez et al., "Natural Language Descriptions of Deep Visual Features"（MILAN）, ICLR 2022, arXiv:2201.11114。Bau et al., "Network Dissection", CVPR 2017, arXiv:1704.05796。Oikarinen & Weng, "CLIP-Dissect", ICLR 2023, arXiv:2204.10965。
  → 「チャネルが何に反応するかを言語化する」道具の部品として使える。ただし説明の忠実性（faithfulness）には既知の問題がある。

### 1.3 Mechanistic Interpretability

- 【事実】Cammarata et al., "Curve Circuits", Distill, 2021 [10]。Olah et al., "Zoom In: An Introduction to Circuits", Distill, 2020 [11]。InceptionV1 の曲線検出器の回路を解析している。
- 【既知文献・要確認】"Curve Circuits" では、研究者が曲線検出の回路を**手で重みを設定して再実装した**と記憶している（本文で再確認が必要）。もし正しければ、**「人間が内部表現を理解して重みを直接書く」ことの先行例**になり、ADLはその人間をAgentに置き換えたものと位置づけられる。
- 【既知文献】ACDC（Conmy et al., NeurIPS 2023, arXiv:2304.14997）、Sparse Autoencoder による特徴分解（Bricken et al., "Towards Monosemanticity", 2023 ほか）。
- 【解釈】mech-interp は「理解」を目的とし、得られた理解を**学習則として使う**ことは主目的にしていない。ADLは「理解 → 編集 → 検証」を閉じたループにする点で異なる。ただし、そのループはWSP [1][3] がすでに閉じている。

### 1.4 Model Editing

- 【事実】Santurkar et al., "Editing a classifier by rewriting its prediction rules", NeurIPS 2021, arXiv:2112.01008 [12]。**CNN分類器**の層の重みを、概念レベルの規則（例：「雪の道路 → 道路」）に従ってランク1更新で書き換える。
- 【既知文献】Bau et al., "Rewriting a Deep Generative Model", ECCV 2020, arXiv:2007.15646（人間がGANの層の規則を直接書き換える）。ROME（Meng et al., NeurIPS 2022, arXiv:2202.05262）、MEMIT（ICLR 2023, arXiv:2210.07229）、MEND（Mitchell et al., ICLR 2022, arXiv:2110.11309）。
- 【解釈】Model Editing は **(i) 人間が編集対象を指定する**、**(ii) 更新式が固定されている**（閉形式の最小二乗、学習済みの編集器など）、**(iii) 局所的な修正であり、能力の獲得ではない**。ADLとの差分は (i)(ii) を Agent に委ね、(iii) を超えることにある。ただし (ii) について、Agentが結局ROME型の最小二乗を毎回選ぶなら、それは「固定則の呼び出し」に退化する（§5で議論）。

### 1.5 Representation Engineering / Activation Steering

- 【既知文献】Zou et al., "Representation Engineering", arXiv:2310.01405, 2023。Turner et al., "Activation Addition", arXiv:2308.10248。Li et al., "Inference-Time Intervention", NeurIPS 2023, arXiv:2306.03341。
- 【解釈】主に推論時の**一時的な**活性編集である。ADLの制約「一時的な活性編集と永続的なパラメータ変更を区別する」に照らすと、steering は**観察・因果検証の道具**としては使えるが、学習の成果物にはならない。ただし、bias や重みに焼き込めば永続化できる（例：方向 u を W から射影除去する [4][1]）。

### 1.6 Learned Optimizers / Hypernetworks / Meta-learning

- 【既知文献】Andrychowicz et al., "Learning to learn by gradient descent by gradient descent", NeurIPS 2016, arXiv:1606.04474。Metz et al., "VeLO", arXiv:2211.09760, 2022。Ha, Dai, Le, "HyperNetworks", ICLR 2017, arXiv:1609.09106。Schmidhuber の fast weight programmers（1992）。
- 【事実・二次確認】NeuronGen（Wang, Zhang, Li, arXiv:2505.12470, 2025）[13] は、LLMを重み生成器として学習させる。機械レビューによれば、Stage 2 で逆伝播を使っている（本文は未確認）。
- 【解釈】学習済みoptimizerとハイパーネットは、**更新規則（あるいは重み生成器）を勾配で学習した、固定された関数**である。ADLとの対応関係は次の通りである。

  | | 更新の入力 | 更新規則 | 規則の獲得法 |
  |---|---|---|---|
  | SGD/Adam | 勾配 | 人手で固定 | 人間 |
  | Learned optimizer | 勾配（＋統計量） | NNで固定 | メタ学習（勾配） |
  | Hypernetwork | タスク記述 | NNで固定 | 勾配 |
  | **ADL（仮説）** | 内部状態の観察＋意味知識＋評価値（**勾配なし**） | 状況ごとにAgentが推論して決める（**非固定**） | Agentの事前学習（勾配）＋文脈内の推論 |

  ただし「Agent = 巨大な learned optimizer であり、更新入力が勾配の代わりに観察になっただけ」という見方は否定しきれない（§5）。

### 1.7 LLM-based Optimization / LLM誘導の進化計算 / 研究Agent

- 【既知文献】Yang et al., "Large Language Models as Optimizers"（OPRO）, ICLR 2024, arXiv:2309.03409。Romera-Paredes et al., "FunSearch", Nature 2024。Lehman et al., "Evolution through Large Models", arXiv:2206.08896。Chen et al., "EvoPrompting", NeurIPS 2023, arXiv:2302.14838。Chen et al., "Symbolic Discovery of Optimization Algorithms"（Lion）, arXiv:2302.06675。Lu et al., "DiscoPOP"（LLMによる損失関数の発見）, arXiv:2406.08414。Lu et al., "The AI Scientist", arXiv:2408.06292。Huang et al., "MLAgentBench", arXiv:2310.03302。
- 【解釈】これらは **LLM = 提案分布（mutation operator）＋評価による選択** という構造である。ADLのループ（観察→推論→操作→検証）も、外形はまったく同じ構造をしている。**ADLが「LLM誘導の進化計算」と区別されるのは、提案が内部表現の観察に条件づけられ、しかもその条件づけが効いていると示せた場合だけ**である。研究Agent系（AI Scientist, MLAgentBench）は逆伝播による学習コードを書くので、ADLの対象外である。

### 1.8 誤差逆伝播に依存しない学習

## 2. Task 2：研究仮説の成立可能性

### 2.1 定式化：「Agentによる学習」とは何か

学習対象を $f_\theta$（パラメータ $\theta \in \mathbb{R}^d$、構造 $\mathcal{A}$）、Agentを $\pi$（凍結されたLLM/VLM、事前知識 $K$）とする。ステップ $t$ で

$$
o_t = \mathrm{Obs}(\theta_t, \mathcal{A}_t, D_t), \qquad
a_t \sim \pi(\,\cdot \mid o_{\le t}, a_{<t}, M_t, K), \qquad
(\theta_{t+1}, \mathcal{A}_{t+1}) = \mathrm{Apply}(a_t; \theta_t, \mathcal{A}_t)
$$

とする。$D_t$ はAgentが選んで投入する入力（データの一部・合成入力）、$M_t$ は記憶である。

ここで重要なのは、**外から見ると $\pi$ と Obs と Apply の合成は、確率的な更新写像 $U: (\theta_t, \mathcal{A}_t, \text{履歴}) \mapsto (\theta_{t+1}, \mathcal{A}_{t+1})$ にすぎない**ということである。SGD、ES、learned optimizer もすべてこの形をしている。したがって「固定された学習則ではない」という主張は、この形式だけからは出てこない。

**【提案】ADLを他の更新写像と区別するために、検証可能な性質として以下を定義する。**

- **(P1) 情報源の性質**：$U$ が依存する情報のうち、$K$（事前知識）と内部観察 $o_t$ の寄与が大きい。操作的には、$K$ を壊す（意味情報の匿名化）か $o_t$ を壊す（内部を見せない）と性能が大きく落ちること。
- **(P2) 標本効率**：同じ順伝播予算・データ量で、ゼロ次最適化（ES/MeZO）やランダム編集を大きく上回ること。
- **(P3) 構造性**：編集が低次元で、意味的に説明可能な構造的変化（チャネルの追加、カーネルの合成、接続の付け替え）であり、その説明が反実仮想テストで忠実であること。
- **(P4) 永続性・自律性**：Agentを外した後も獲得した能力が残り、未知データに汎化すること。

(P1) と (P2) がなければ、ADLは「LLMを提案分布とする進化計算」と区別できない。

### 2.2 情報理論的な制約：Agentは「何を変えるべきか」をどこから知るのか

逆伝播は、1回の順伝播＋逆伝播で $d$ 次元の勾配、つまり $d$ 個の方向別感度を得る。勾配なしの場合、Agentが得られる情報は次の3つに限られる。

1. **事前知識 $K$**：「エッジ検出器は Gabor 型であるべき」「人の検出には頭部・胴体の部位特徴が要る」など。
2. **順伝播による観察**：活性、出力、アブレーション結果。1回の介入実験で得られるのは、高々「その介入の効果」というスカラーまたは低次元の情報である。
3. **評価値**：精度・損失のスカラー。

ゼロ次の勾配推定は、一般に1ステップあたり $O(d)$ 回の関数評価を必要とする（あるいは分散が $O(d)$ に比例して大きくなる）。ADLが実用的に成立するには、**$K$ と内部観察によって、探索すべき有効次元 $d_\text{eff}$ が $d$ より桁違いに小さくなっている**必要がある。

**【仮説 H1（中心仮説の精密化）】** Agentの事前知識と内部観察は、「どの層・どのチャネル・どの形状の変化が必要か」を推論させる。それにより、パラメータ空間の探索を $d_\text{eff} \ll d$ の構造化部分空間に制限する。その結果、同じ評価回数のもとで、ゼロ次最適化より高い標本効率で能力を獲得できる。

この仮説は反証可能である。$K$ を剥奪した条件で性能が変わらなければ H1 は棄却される。

### 2.3 必要な情報

| 情報 | 必要性 | 理由 |
|---|---|---|
| 入力画像（Agentが見る） | 高 | VLMの意味知識を使う前提 |
| 構造・形状 | 必須 | 操作の対象を特定するため |
| チャネルごとの応答の要約（top-k パッチ、言語記述） | 高 | 生の数値より圧倒的に情報密度が高い |
| 因果的介入の結果（アブレーション、パッチング） | 高 | 相関的説明の誤り（[7] のような失敗）を防ぐ |
| 生の重み | 中 | 初期層（3×3×3など）は可視化で十分理解できる。深い層ではほぼ読めない |
| 評価値（dev セット） | 必須 | ただし過剰適合の温床になる（§2.6） |
| 勾配 | **原則禁止** | ただし「解析目的の入力勾配（saliency）は許すか」は要決定（§3.4） |

### 2.4 操作の粒度

| 粒度 | 例 | 長所 | 短所 |
|---|---|---|---|
| スカラー | 個々の重み | 完全な表現力 | Agentのトークン予算で破綻する。意味と対応しない |
| カーネル／ニューロン | 3×3 カーネルを書く、1列を変える | 初期層では意味と対応する | 深い層では入力チャネルが数百あり、直感が効かない |
| 低ランク・方向 | $W \leftarrow W + \alpha\, u v^\top$、方向の射影除去 | WSP [1][4][6] で有効性が実証されている。少ない自由度 | $u, v$ の選び方に計算が要る（そこで固定則が忍び込む） |
| チャネル／構造 | add/remove channel、接続の付け替え | 「新しい特徴の獲得」に直結 | 後続層との整合を取る必要がある |
| プログラム | 重みを生成するコードを書く [3] | 規則的な構造（回転したカーネル群など）を一括で表現できる | コードの中で最小二乗や勾配を実装すれば、規則上の抜け穴になる |

**【解釈】** 現実的な主戦場は「低ランク・チャネル・プログラム」の3つである。スカラー単位の編集は、比較用のベースラインに留めるべきである。

### 2.5 数学的な問題

1. **対称性・非同定性**：ReLUネットでは、チャネルの置換対称性と正のスケール対称性（$W_\ell \to c W_\ell,\ W_{\ell+1} \to W_{\ell+1}/c$）がある。「意味のある表現」が一意に定まらない。Agentの「この重みはこうあるべき」という判断は、等価な無数の解のうち1つを指すにすぎない。
2. **分散表現・superposition**：深い層の特徴は多義的（polysemantic）で、1チャネル＝1概念にならない。チャネル単位の意味的編集が前提とする対応関係が崩れる。
3. **相互作用と干渉**：ある編集は、下流のすべての層を通じて別の能力に影響する。逆伝播は全パラメータの一次の影響を同時に勘定するが、Agentは少数の介入から推測するしかない。**忘却（retention の低下）が最大のリスク**である。
4. **Credit assignment**：多層での誤差の帰属は、逆伝播が解いている問題そのものである。Agentが層をまたいで「どこを変えるべきか」を決めるには、(a) 中間層の目標表現を自分で定義する（target propagation に相当）か、(b) 介入実験で帰属を測る（ゼロ次推定に相当）か、のどちらかが必要になる。**(a) をAgentの意味知識で行う点が、ADLの数少ない原理的な独自性の候補**である（【仮説 H2】：Agentは、中間層の目標表現を意味的に定義することで、層ごとの局所問題に分解できる）。
5. **収束性・安定性**：Agentの更新写像は確率的で、非定常で、文脈長に依存する。収束を保証する理論的道具は現状ない。最低限、checkpoint/rollback による単調受理（dev 性能が改善したときだけ採用する）にすれば、「dev 上で非減少」は保証できる。ただしこれは貪欲な局所探索そのものである。
6. **BatchNorm 等の正規化**：統計量と重みのスケールが結合していて、編集の効果が非直感的になる。最小実験では BN を外すか、凍結して再推定を禁止すべきである。

### 2.6 計算量とスケーラビリティ

**【推測を含む見積もり】** 1回のAgentステップを、入出力数万トークンのLLM推論とする。これはGPU数秒〜数十秒、コストにして数セント〜数十セントのオーダーである。小型CNN（10⁵パラメータ）の SGD 1エポックはGPUで数秒以下で済む。したがって**計算時間では、ADLが逆伝播に勝つ見込みはほぼない**。参考として、iWSP [3] は全実験で約17,500ドル（定価換算）と報告している【事実】。

ADLが主張しうる優位は、計算量ではなく以下の点に限られる。

- **標本効率**：少ないデータ・評価回数で獲得できる（H1）。
- **解釈可能性**：なぜその編集をしたかが記録に残る。
- **目的の言語的指定**：「背景ではなく形状で判断せよ」のような、損失関数に書きにくい目標を扱える。

スケールについては、WSP [1] でも Qwen 0.8B で 0.016% の重み編集が成功している。一方 [6] では 9B で held-out が改善せず、[4] では 27B 未満で失敗している。**モデルが大きくなるほど編集は「既存能力の再配線」に限られる**と見るのが妥当である【解釈】。「ゼロから大規模CNNを学習させる」ことは、現実的な目標にすべきでない。

### 2.7 成立可能性の暫定評価

| 主張 | 評価 | 根拠 |
|---|---|---|
| Agentが内部表現を観察し、勾配なしで永続的に編集できる | **ほぼ成立（既に実証済み）** | [1][2][3][4] |
| 編集によって既存能力の修復・除去・再配線ができる | **成立（実証済み）** | [1][2][6] |
| Agentが既に知っているアルゴリズム・特徴を書き下せる | **成立（実証済み）** | [1] MinAtar・囲碁、[3] アルゴリズム課題 |
| **データから、Agentの事前知識にない特徴を発見し、獲得できる** | **未検証。否定的な示唆あり** | [1] の「能力は加えられなかった」、[3] の「新しい原理は発明しない」 |
| 多層の階層的表現を、Agentが意味的に設計して形成できる | 未検証 | 該当する実証は見当たらない |
| 逆伝播やESより標本効率が良い | 未検証 | 公平な比較がない（[1] は公平な順位付けではないと自ら述べている） |

**ADLの研究価値は、表の太字の行にほぼ集約される。**

## 3. Task 3：Agent環境（ツール）の設計

### 3.1 設計原則

1. **抽象度の階層**：生テンソル → 統計・可視化 → 意味的要約 → 因果テスト、の各段を道具として分ける。どの段の情報が学習に効いたかを、アブレーションで測れるようにするためである。
2. **計量と監査**：WeightBench [5] にならい、重みに対する数値演算（FLOP）、順伝播回数、生の重みの読み出しをすべて記録する。勾配計算と optimizer の呼び出しはサンドボックスで遮断する。
3. **「固定則の抜け穴」の可視化**：最小二乗・PCA・回帰などの「当てはめ」系の演算は、禁止はせず**フラグを付けて記録する**。後で「Agentが固定則を呼んでいただけか」を判定するためである（§5）。
4. **データの封印**：dev と held-out を分け、held-out には一切アクセスさせない。
5. **永続変更と一時介入の型による区別**：`probe_*`（一時的、モデルは不変）と `edit_*`（永続的、checkpoint 対象）を名前と型で分ける。

### 3.2 観察ツール

| ツール | 入力 | 出力 | 操作対象 | 期待する効果 |
|---|---|---|---|---|
| `inspect_model()` | なし | 層グラフ、各層の形状、パラメータ数、正規化の有無 | 構造 | 操作対象の特定 |
| `get_tensor(layer, slice, fmt)` | 層名、スライス、形式（raw / 量子化 / 統計） | 数値（上限付き）、平均・分散・ノルム・スパース性 | 重み・bias | 小さなカーネルの直接読解。読み出し量は計量する |
| `render_kernels(layer, channels)` | 層、チャネル | 画像（RGBカーネル、入力チャネルごとのヒートマップ） | 初期層カーネル | VLMの視覚知識を直接使う |
| `feature_map(layer, channel, inputs)` | 層、チャネル、入力ID | 活性マップを入力に重ねた画像＋統計 | 活性 | どこに反応しているかを見る |
| `top_activations(layer, channel, k, pool)` | チャネル、プール（dev データ） | 最大活性のパッチ k 枚（受容野で切り出し） | 活性 | チャネルの意味を推定する。Network Dissection の簡易版 |
| `describe_channel(layer, channel)` | チャネル | 言語による仮説＋確信度（MILAN/MAIA 型の下位エージェントでもよい） | 活性 | 意味的要約。ただし忠実性は §3.4 で検証する |
| `concept_probe(layer, concept_set)` | 層、概念ごとのラベル付き入力 | 各概念とチャネルの対応度（IoU / AUROC） | 活性 | 「どの特徴が不足しているか」を定量化する。**閉形式の線形プローブは当てはめとしてフラグ記録** |
| `channel_similarity(layer)` | 層 | チャネル間の相関・重み空間でのクラスタ | 重み・活性 | 冗長な特徴、統合・分離の候補を見つける |
| `predict(inputs)` | 入力 | 出力分布、混同行列 | 出力 | 誤りの把握 |

### 3.3 因果的介入ツール（一時的、モデルは不変）

| ツール | 入力 | 出力 | 期待する効果 |
|---|---|---|---|
| `probe_ablate(layer, channels, inputs)` | 無効化するチャネル | 出力・下流活性の変化 | 因果的な寄与の測定。相関的説明の誤りを検出する |
| `probe_patch(layer, channel, src, dst)` | 活性の移植元・移植先の入力 | 出力変化 | 「このチャネルが概念Xを運んでいるか」の検証 |
| `probe_steer(layer, direction, α)` | 活性空間の方向 | 出力変化 | 永続編集の前の試し打ち |
| `probe_edit(edit_spec, inputs)` | 永続編集と同じ仕様 | 編集した場合の結果（モデルは不変） | 予測→検証を安価に行う |
| `synthesize_inputs(spec)` | 言語または手続きによる仕様 | 合成画像 | 反実仮想入力（「同じ形状で背景だけ違う」など）。**生成器が外部知識を持ち込む交絡に注意** |

### 3.4 数値演算ツール

| ツール | 内容 | 注意 |
|---|---|---|
| `tensor_sandbox(code)` | NumPy で重み・活性を解析・合成する（SVD、畳み込み、回転、ノルム調整など） | FLOP を計量する。`autograd`/optimizer は遮断する。**最小二乗・回帰・反復的当てはめは検知してフラグを付ける** |
| `compose_kernel(ops)` | 「既存カーネル A を 45° 回転し、B と和を取る」などの宣言的な合成 | 意味的操作と数値操作の橋渡し。プログラムの形で編集を記録できる |
| `receptive_field(layer, channel)` | 入力空間での受容野と実効カーネル（線形近似） | 多層の合成効果の理解 |
| `input_saliency(...)` | 入力に対する勾配 | **要決定**。対象モデルのパラメータ勾配ではないが、勾配情報である。実験因子として「許可／不許可」の両条件を設けることを提案する |

### 3.5 永続操作ツール

| ツール | 入力 | 操作対象 | 期待する効果 |
|---|---|---|---|
| `edit_kernel(layer, out_ch, values / expr)` | 値または式 | カーネル1つ | 初期層の特徴の直接形成 |
| `edit_lowrank(layer, u, v, α)` | ベクトル、係数 | 重み行列 | 方向の追加・除去（WSPで実績のある操作） |
| `scale_channel(layer, ch, s)` / `set_bias(...)` | 係数 | チャネル | 強化・抑制、しきい値の調整 |
| `add_channel(layer, init_spec)` | 初期化仕様（カーネル式、下流への接続重み） | 構造＋重み | **新しい特徴の獲得**（ADLの中核操作） |
| `remove_channel(layer, ch)` | チャネル | 構造 | 不要特徴の削除 |
| `connect(src_layer, src_ch, dst_layer, dst_ch, w)` | 接続仕様 | 次層の入力重み | 特徴の合成（階層表現） |
| `merge_channels / split_channel` | チャネル群 | 構造＋重み | 統合・分離 |
| `write_weights_program(code)` | 重みを生成するコード | 任意 | 規則的な一括操作 [3]。演算は計量する |

### 3.6 検証・記憶ツール

| ツール | 内容 |
|---|---|
| `evaluate(split="dev", suites=[...])` | 新タスク・旧タスク（retention）・頑健性スイートの評価。回数に予算を設ける |
| `diff(ckpt_a, ckpt_b)` | 変化したパラメータ、変化量、影響を受けたチャネル |
| `checkpoint(tag, rationale)` / `rollback(tag)` | 編集の理由とともに保存する |
| `ledger` | 仮説→編集→予測→結果→採否、を構造化して記録する。**研究データそのもの**として扱う |
| `memory_query(...)` | 過去の成功・失敗、獲得済み／未獲得の特徴の検索 |

### 3.7 予算（実験条件として固定する）

順伝播回数、評価回数、生の重みの読み出し量、FLOP、トークン数、壁時計時間。**比較対象（ES、ランダム編集）にも同じ順伝播予算を与える**ことが公平性の前提である。

## 4. Task 4：最小構成での概念実証

### 4.1 設計の要点：何を示せば「学習した」と言えるか

プロジェクト方針 §9 にある通り、「Agentが既知のエッジ検出カーネルを書ける」ことは何も示さない（WSP [1] の MinAtar がまさにそれに当たる）。最小実験は、次の4条件を同時に満たす必要がある。

1. **新規性**：獲得すべき特徴が、Agentの事前知識の中で名前を持たない（教科書的な Gabor・Sobel・既知の物体部位ではない）。
2. **データ依存**：その特徴は、データを観察することでしか特定できない。言語による仕様は与えない。
3. **永続性**：重み・構造の変更として残り、Agentなしで動作する。
4. **非自明性**：決め打ちの単純な規則（後述の matched filter）では解けない、または Agent がそれより効率的であることを示せる。

### 4.2 提案する実験 E1：「名前のない局所パターン」の後付け獲得

**データ**：64×64 の合成画像。背景はランダムなテクスチャや図形。

- **基礎概念**（事前に逆伝播で学習済み。方針 §6 で許容される「部分的に学習済みのモデル」）：円・四角・三角の分類など。
- **新概念 X**：手続き的に生成した、**意味的な名前を持たない**局所構造。例えば「特定の2色が特定の角度で接する T 字状の接合」「ある周期と位相をもつ非対称な縞の断片」。これを位置・スケール・回転にある程度ばらつかせて配置する。ラベルは「X を含むか否か」。
  - 統制として、意味的な名前を持つ新概念（例：「星形を含む」）でも同じ実験を行い、事前知識の効果を分離する。
- **データ量**：新概念は少数（例：正例・負例 各50〜200枚）。少数データでの獲得が H1（標本効率）の検証になる。

**モデル**：3〜4層の小型CNN（BNなし、10⁴〜10⁵パラメータ）。基礎概念で学習した後に凍結。新概念用の出力ユニットを1つ追加し、その重みは0で初期化する。**初期状態では X を検出できないこと**（AUROC ≈ 0.5）を確認しておく。

**Agentの課題**：「この出力が X の有無を判定できるようにせよ」。X が何であるかは知らせず、正例と負例の画像だけを与える。

**期待される解のパターン（Agentに教えない）**：X に反応するチャネルを中間層に新設し（`add_channel`）、既存の初期層特徴（色・方向）を合成して作り（`connect`）、出力に接続する。**既存表現の再利用と新しい表現の形成**が同時に必要になるように課題を設計する。

### 4.3 比較条件（アブレーション）

| 条件 | 目的 |
|---|---|
| **A. Full Agent**（VLM、全ツール） | 主条件 |
| **B. 意味剥奪**：画像を見せない（テンソル統計のみ）、チャネルや出力に匿名IDのみ | 事前知識 $K$ の寄与（P1） |
| **C. 内部観察剥奪**：入出力と評価値、永続編集ツールのみ | 内部観察の寄与（P1） |
| **D. ランダム編集**：同じ操作空間・同じ予算 | 下限 |
| **E. ES / CMA-ES / MeZO**：同じ操作空間（新チャネル＋接続）・同じ順伝播予算 | **ゼロ次最適化との比較（P2）。最重要** |
| **F. Matched filter 則**：正例パッチの平均 − 負例パッチの平均をカーネルとし、閉形式で読み出しを決める | 「固定則で十分ではないか」への回答 |
| **G. 逆伝播**：同じパラメータ部分だけを SGD で学習 | 上限の参考（勝つ必要はない） |
| **H. Agent＋「当てはめ」禁止** | Agentがコード内で最小二乗を実装して解く経路を塞いだ場合の性能 |

### 4.4 評価項目

- 新概念の AUROC（dev／**封印した held-out**／分布シフト：位置・スケール・背景の変化）
- 基礎概念の精度の保持（retention）
- **Agentを外した状態**での推論性能（永続性）
- 順伝播回数・評価回数・トークン数・壁時計時間
- 編集の構造（変更パラメータ数、追加チャネル数）と、ledger 上の説明の**忠実性**（説明した役割をアブレーションで確認できるか）
- 複数シード（モデル初期化×Agentの乱数×X の種類）での分散

### 4.5 成否の判定基準（事前登録を推奨）

- **最低限の成立**：A が held-out で AUROC ≫ 0.5（例 0.9 以上）を達成し、retention の低下が小さく、Agentなしで動作する。
- **ADLとして意味がある**：A が E（ES）を同じ予算で有意に上回り、**かつ** B または C で性能が大きく落ちる。
- **ADLの仮説が棄却される**：A ≈ B ≈ C、または A ≈ E。この場合「Agentは汎用の探索器として働いているだけ」と結論する。
- **固定則への退化**：A の解が F とほぼ同一であり、ledger 上も matched filter 型の当てはめを使っている。

### 4.6 段階的な拡張

- **E2（階層・credit assignment）**：X を「部品 P と部品 Q が特定の空間配置にある」とする。2層にまたがる形成が必要になる。H2（中間目標の意味的定義）を検証する。
- **E3（継続学習）**：X₁, X₂, … を順に獲得させ、忘却と表現の再利用を測る。
- **E4（自然画像）**：「人」の検出を部位特徴から構成するなど、ユーザーの当初の着想に近い課題。ここで初めてVLMの意味知識が本格的に効くはずである。ただし、Agentが既知の知識を書き下しているだけなのか、データから学んでいるのかを区別するのは、E1 より難しい。

## 5. Task 5：新規性と批判

### 5.1 既存の枠組みとの本質的な差

| 比較対象 | 差分として主張できること | その主張の弱点 |
|---|---|---|
| **WSP** [1–6] | データからの帰納的な能力獲得、CNNの階層表現、VLMによるクロスモーダルな比較 | WSP は「概念」として自らを定義しており [1]、ADLはその部分集合と見なされやすい。iWSP [3] はすでに精度フィードバックによる反復構築をしている |
| Model Editing | 編集対象と更新式をAgentが決め、能力を獲得する | Agentが ROME 型の最小二乗を毎回選ぶなら、差分は「誰が呼び出したか」だけになる |
| ブラックボックス最適化／進化計算 | 提案が内部観察と意味知識に条件づけられる | 外形は OPRO/FunSearch と同一。条件づけの効果を実験で示せなければ区別できない |
| Learned optimizer | 規則が固定されず、文脈内推論で決まる | Agentも勾配で学習された固定の関数である。「文脈内で規則が変わる」のは、learned optimizer の状態依存性とどこが違うのか、明確な線は引けない |
| 局所学習則（Hebb、FF など） | 規則を事前に固定しない | 規則を固定しないことは、利点であると同時に再現性・解析可能性を損なう |
| 知識蒸留 | 教師の出力ではなく、内部を直接書く | Agentの知識は、もともと逆伝播で学習されたネットワーク群から得たものであり、「逆伝播の産物を間接的に蒸留しているだけ」という批判は免れない |

### 5.2 「Agentが既存の最適化を実行しているだけ」になる経路

1. **コード経由**：Agentが `tensor_sandbox` 内で最小二乗・PCA・反復的な当てはめを書き、実質的に固定則で学習する。iWSP [3] も「Pythonで学習してしまうことはハーネスでは防げないので、事後監査した」と述べている【事実】。
2. **試行錯誤経由**：観察をほとんど使わず、「編集→評価→採否」を繰り返す。これは LLM を提案分布とした (1+1)-ES である。
3. **記憶経由**：事前学習で見た「学習済みCNNのフィルタの典型」を書き下す。これは学習ではなく再生である。[7] は、重みの「読解」が事前知識（データセットの典型的なラベル順）に大きく依存していることを示しており、この懸念を裏づける【事実】。

**判定の方法（提案）**：
- 経路1 → 演算の計量とフラグ、条件 H（当てはめ禁止）。
- 経路2 → 条件 C・E との比較。ledger 上の「予測が当たった率」を測り、推論がランダムな提案より良いかを確認する。
- 経路3 → 名前のない概念 X（E1）と、名前のある概念との性能差を見る。

### 5.3 より根本的な批判

- **「学習主体」という主張の検証可能性**：「Agentが学習主体である」というのは、哲学的な主張になりやすい。§2.1 の (P1)〜(P4) のような**操作的な定義に落とさない限り、論文の主張として査読に耐えない**と考える。
- **計算コスト**：§2.6 の通り、計算量でADLが逆伝播に勝つ見込みはない。「何のためにADLを使うのか」（標本効率、解釈可能性、言語的な目標指定、勾配が使えない環境）を明示しないと、研究の動機が弱くなる。
- **スケールの壁**：WSP では、規模が大きくなると held-out 性能が改善しない例 [6] と、規模が大きくないと失敗する例 [4] が混在している。ADLが小型CNNで成功しても、それが一般化するという主張にはならない。
- **評価への過適合**：Agentは dev セットを繰り返し評価するので、dev への過適合が起きやすい。WSP でも dev での改善が held-out に転移しない報告がある [6]【事実】。held-out の封印と事前登録が必須である。
- **交絡**：VLMの性能、ツールの出来（特に `describe_channel` の忠実性）、プロンプトの設計が結果を左右する。「ADLの原理が効いた」のか「ツールが良かった」のかを分離するアブレーションが要る。

### 5.4 結論：新規性はどこに残るか

**【解釈】** 「LLM Agent による勾配なしの内部編集」という**手段そのものには、新規性はもう残っていない**。残っている可能性があるのは、以下の**問いと検証**である。

1. **帰納的獲得**：Agentの事前知識にない特徴を、データから発見して永続的に獲得できるか。WSP原典が「できなかった」と述べている点への正面からの挑戦である（E1）。
2. **意味的 credit assignment**：Agentが中間層の目標表現を意味的に定義することで、多層の credit assignment を局所問題に分解できるか（H2、E2）。
3. **「Agentは学習アルゴリズムとしてどう振る舞うか」の科学**：事前知識と内部観察が、探索の有効次元をどれだけ減らすか（H1）。ゼロ次最適化と同じ予算で比較し、その差を情報源のアブレーションで分解する。
4. **VLMの知覚とCNN内部表現のクロスモーダルな比較**による「不足特徴の特定」。ユーザーの元々の着想であり、今回の調査範囲では直接の先行例を確認できなかった（ただし [2] の詳細は未確認）。

ただし、この分野は週単位で進んでいるため、上記1〜4のどれかが数か月以内に他所で発表される可能性は高い【推測】。**速度と、比較の厳密さ（同予算のES比較・情報源のアブレーション・名前のない概念）で差別化する**のが現実的な戦略だと考える。

## 6. 確認された事実

- 2026-11-02 に MIT CSAIL の Takehi らが WSP を提唱した。LLMが重みを勾配なしで読み・編集し・ゼロから書く実験を報告している（CNNは含まない）[1]。
- LLMが道具群を使って ResNet・ViT を勾配なしに編集する研究がある（2026-11-19）[2]。
- LLMエージェントが、精度フィードバックを見ながら反復的に重みを書いてモデルを構築する研究がある [3]。
- LLMが自分自身の重みを勾配なしで書き換え、held-out 性能を改善した報告がある（27Bのみ成功）[4]。
- WSPの原典は「持っていない能力は加えられなかった」と述べている [1]。iWSPは「新しい原理は発明しない」と述べている [3]。
- 重みの読解は事前知識に依存している可能性を示す批判的追試がある [7]。
- MAIA は対象モデルの重みを編集しない [9]。

## 7. 新たな研究仮説

- **H1**：事前知識と内部観察は、探索の有効次元を $d_\text{eff} \ll d$ に減らす。そのため、同じ評価予算でゼロ次最適化より高い標本効率を実現する。
- **H2**：Agentは中間層の目標表現を意味的に定義することで、多層の credit assignment を層ごとの局所問題に分解できる。
- **H3（反仮説として検証すべきもの）**：Agentの成功は、事前知識にある既知特徴の再生に限られる。名前のない特徴は獲得できない（WSP [1][3] の示唆）。

## 8. 提案手法（未検証、手法は未確定）

- 観察・因果介入・数値演算・永続操作・検証・記憶を**抽象度の階層ごとに分けた**ツール群（§3）。演算の計量と、当てはめのフラグ付けを含む。
- 「Agentによる学習」の操作的定義 (P1)〜(P4)（§2.1）。
- 最小実験 E1「名前のない局所パターンの後付け獲得」と、8条件の比較（§4）。

## 9. 理論的な問題点

- Agentの更新写像は、形式的には他の確率的最適化と区別できない。区別は経験的にしか示せない。
- ReLUの対称性、superposition、BNによる非同定性のために、「正しい内部表現」という概念自体が曖昧である。
- 収束・安定性の理論がない。単調受理による保証は、貪欲な局所探索と同じものにすぎない。
- Agentの知識自体が逆伝播の産物であり、「逆伝播の代替」という主張の範囲を慎重に限定する必要がある。

1. [2] と [3] の本文を精読し、E1 と重なる実験がないか確認する（特に [2] の課題設定とツール仕様）。

3. H1 を測るための評価予算の設計（ESとの公平な比較条件）を決める。

## 12. ChatGPTへの共有事項（独立した検討を依頼したい点）

1. **WSP潮流（[1]〜[6]）を踏まえて、ADLの新規性は §5.4 の4点に残ると考えるか。** 見落としている先行研究、特に「LLMがデータから新しい特徴を帰納的に獲得した」報告があれば挙げてほしい（実在確認できるもののみ）。
2. **§2.1 の操作的定義 (P1)〜(P4) は妥当か。** 「固定された学習則ではない」ことを示すための、より良い基準はあるか。
3. **E1 の設計の穴**：「名前のない概念」が、実は VLM にとって記述可能（例：「赤と青のT字接合」と言語化できる）であれば、事前知識の剥奪にならない。より良い概念の作り方はあるか。
4. **H2（意味的な中間目標による credit assignment）** は target propagation と本質的に何が違うのか。違わないなら、それでも研究価値はあるか。
5. 本報告の批判（§5.3）に対する反論があれば、遠慮なく提示してほしい。
